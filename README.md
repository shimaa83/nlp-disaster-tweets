\# Disaster Tweet Classification API A production-ready NLP microservice that classifies tweets into disaster-related or non-disaster events using an optimized Scikit-Learn TF-IDF pipeline exported to ONNX format and served via FastAPI with \`onnxruntime\`. Built with MLOps best practices including structured logging, correlation tracking, strict input validation, and containerized deployment. \#\# Quickstart (Zero to Prediction in 3 Commands) \`\`\`bash \# 1\. Clone & setup environment git clone https://github.com//nlp-disaster-tweets.git && cd nlp-disaster-tweets && uv sync \# 2\. Export model to ONNX uv run python \-m src.nlp\_disaster\_tweets.export \# 3\. Launch API server uv run uvicorn src.nlp\_disaster\_tweets.api.main:app \--port 8000 \`\`\` \#\# Example Prediction (\`curl\`) \`\`\`bash curl \-X 'POST' \\ 'http://localhost:8000/predict' \\ \-H 'accept: application/json' \\ \-H 'Content-Type: application/json' \\ \-d '{ "text": "Severe wildfire spreading near residential area, immediate evacuation ordered\!" }' \`\`\` \*\*Response:\*\* \`\`\`json { "prediction": 1, "model\_version": "0.1.0", "correlation\_id": "a1b2c3d4-e5f6-7890-abcd-1234567890ab", "latency\_ms": 4.12 } \`\`\` \#\# Repository Structure \`\`\`text nlp-disaster-tweets/ ├── data/ │ └── train.csv ├── docker/ │ ├── Dockerfile │ └── docker-compose.yml ├── models/ │ ├── model.pkl │ └── model.onnx ├── reports/ │ └── module-1.md ├── src/ │ └── nlp\_disaster\_tweets/ │ ├── api/ │ │ ├── main.py │ │ └── schemas.py │ ├── base.py │ ├── config.py │ ├── context.py │ ├── data.py │ ├── export.py │ ├── features.py │ ├── logging\_conf.py │ ├── predict.py │ └── train.py ├── tests/ │ ├── conftest.py │ ├── test\_api.py │ ├── test\_features.py │ ├── test\_predict.py │ └── test\_serialization.py ├── .dockerignore ├── pyproject.toml ├── README.md └── uv.lock \`\`\`
